# Good КП

Разбор коммерческого предложения глазами клиента. Методика [Вадима Школьного](https://t.me/ShkolnyiAccount), сборка [Кристины Винтер](https://t.me/vintersbrain).

**Пример отчета:** скачайте [examples/stroymarket.html](examples/stroymarket.html) и откройте в браузере.

![Good КП](docs/preview.png)

## Зачем

Вы отправляете КП. На стороне клиента его читают трое: тот, кто платит, тот, кто продвигает проект внутри, и тот, кто будет с этим жить после запуска. У каждого свой вопрос к документу. Если ответа в КП нет, вопрос задают вам, и обычно в невыгодной форме.

Good КП собирает этих троих синтетически, читает документ их глазами и отдает один HTML-файл: что подумал каждый, на каких из шести опор КП держится и где отваливается, что переписать за час и как выглядит исправленная первая страница. Файл открывается в любом браузере, интерактивный, без серверов.

## Шесть опор

| | Опора | Вопрос клиента |
|---|---|---|
| 1 | Проблема | Вы поняли, что у меня болит? |
| 2 | Цели и метрики | Что изменится и как мы это измерим? |
| 3 | Решение | Как именно это решает мою задачу? |
| 4 | Как сделаем | Что произойдет по шагам и что нужно от меня? |
| 5 | Почему вы | Чем вы отличаетесь от двух других КП у меня на столе? |
| 6 | Почему точно | Чем я рискую и как вы это снимаете? |

## Как устроено

Весь интерфейс живет в одном файле `template/report.html`. Модель возвращает только данные по схеме `schema/report.schema.json` и никогда не пишет разметку. Поэтому отчет у всех одинаковый, а поведение предсказуемое.

```
КП (pdf, docx, pptx, txt) + ответы на шесть вопросов
  -> текст с якорями абзацев
  -> модель, структурированный вывод по схеме
  -> валидация, типографика, проверка голоса
  -> JSON внутри template/report.html
  -> report.html
```

Два пути к одному и тому же файлу:

- **Без кода.** Файл `paste.html` из репозитория и `prompt.md`. Вставляете КП в чат с моделью, получаете JSON, вставляете его в открытый файл, скачиваете отчет.
- **Из терминала.** `uv run goodkp run kp.pdf --answers answers.yaml`. Тот же шаблон, тот же результат.

## Структура

```
goodkp/
  schema.py        контракт данных (pydantic), экспорт JSON-схемы
  render.py        вставка JSON в шаблон, сборка автономного HTML
template/
  report.html      шаблон отчета: стили, рендер из JSON, интерактивы
schema/
  report.schema.json
scripts/
  extract_golden.py   эталонные данные из прототипа
  expected_text.py    ожидаемый текст секций для теста эквивалентности
tests/
  golden/stroymarket/report.json   эталонный отчет
  test_schema.py  test_render.py  test_golden.py  test_ui.py
examples/
  stroymarket.html  собранный эталонный отчет
docs/
  spec.md          дизайн системы
```

## Запуск

```bash
uv sync --group dev
uv run playwright install chromium
uv run pytest -q
```

Собрать отчет из готового JSON:

```bash
uv run python -c "import json; from goodkp.render import render; from goodkp.schema import Report; open('report.html','w').write(render(Report.model_validate(json.load(open('tests/golden/stroymarket/report.json')))))"
```
